# Первый запуск Forte Vision на NVIDIA Brev

Этот этап публикует текущий сайт: лендинг, гостевой просмотр демонстрации, темы и языки. Модель и сервер анализа ещё не входят в этот репозиторий. Адреса `/api/v1/analyze` и `/api/v1/jobs/{job_id}` пока не реализованы. Публичную ссылку первого запуска нельзя выдавать за готовое решение для жюри.

## Запуск

На выбранной машине Brev нужны Docker Engine с Compose v2 и доступ к исходникам этого проекта. Для самого сайта GPU не используется. Уже обученную модель можно добавить отдельным сервисом позже, после проверки её требований к GPU.

Загрузите проект на машину через Git или SCP, перейдите в его папку и выполните:

```bash
cp deploy/brev/runtime.env.example deploy/brev/runtime.env
bash scripts/deploy-brev.sh
```

Контейнер запускает production-сервер Vinext на порту 3000, перезапускается после перезагрузки машины и проверяет доступность главной страницы. Первый запуск собирает проект и требует интернета для установки зависимостей. Веса моделей в образ не включены.

В Brev откройте Access выбранной машины и настройте доступ к порту 3000. Нужен публичный HTTPS-адрес. Для теста через свой компьютер можно использовать SSH port forwarding. Обратите внимание: согласно документации Brev, ссылки Tunnels требуют авторизации в браузере при первом открытии. Наличие такой ссылки ещё не подтверждает доступность API для автоматической проверки жюри. Для сдачи потребуется доступный извне API без браузерной авторизации.

После настройки адреса проверьте:

```bash
curl -I https://YOUR_PUBLIC_HOST/
curl -I https://YOUR_PUBLIC_HOST/demo
```

Ожидается HTTP 200. `/demo` открывается как гостевой просмотр. Демонстрационные записи помечены как примеры. Введённый пользователем адрес внешнего API по-прежнему позволяет подключить отдельный сервер команды.

## Доступ

Приложение открывается без регистрации и входа. `/app` — основное рабочее пространство, `/demo` перенаправляет туда. Переменные Supabase и почтовая конфигурация больше не используются. Ключ `X-API-Key` для сервера анализа настраивается отдельно и не является пользовательским аккаунтом.

## Обновление

Обновите исходники из вашей рабочей ветки или замените их новой версией, сохранив runtime.env. Затем повторите:

```bash
bash scripts/deploy-brev.sh
```

Compose пересоберёт сайт и заменит контейнер. Возможен короткий перерыв. Текущая история проверок находится в памяти вкладки браузера и не является серверной базой данных.

Просмотр журналов и остановка:

```bash
docker compose --project-name forte-vision --env-file deploy/brev/runtime.env -f deploy/brev/compose.yaml logs --tail=100 web
docker compose --project-name forte-vision --env-file deploy/brev/runtime.env -f deploy/brev/compose.yaml stop
```

Остановка контейнера не останавливает оплату GPU-машины. Расходы управляются отдельно в Brev.

## Что проверено до доступа к машине

TypeScript, тесты приложения и сборка проверяются в рабочем окружении. Docker-образ и запуск на NVIDIA Brev нужно проверить на целевой машине: Docker daemon и доступ к аккаунту Brev здесь отсутствуют.
