## Подтверждено

- `pnpm test`: 105 тестов, включая транспорт, хранилище заданий, hook, границы времени, навигацию и отсутствие ложного вердикта.
- `pnpm typecheck`: без ошибок.
- В Chrome воспроизведён MOV с H.264, 640×360, 12 секунд. Фрагмент 1–7 с стартует с 1 с и автоматически останавливается на 7 с; после возврата сохраняется позиция. Фокус переходит на заголовок экрана.
- Активное задание видно в истории и из раздела источников; отмена оставляет доступную кнопку продолжения. После перезагрузки восстанавливаются метаданные, ключ нужно ввести заново. Возобновление и добавление локального MOV оставляют счётчик POST равным 1.
- Ответ `failed` показывает ошибку без вердикта и экспорта; запись остаётся в истории. Временный HTTP 503 завершается готовым результатом с одним POST.
- На окне Chrome 1363×936 нет горизонтального переполнения страницы. Колонка «Видеозапись» — 220 px. Предупреждения результата помещаются в одну строку; шапка имеет `position: sticky`.

## Повторная проверка без модели

Ручной стенд включается только в dev:

```bash
FORTE_FRONTEND_FIXTURES=1 pnpm dev
```

Откройте `/__frontend-fixtures`, выберите `success`, `slow`, `failed`, `reconnect`, `outside`, `dense`, `frames` или `unknown-progress`. В интерфейсе оставьте адрес API пустым, укажите фиктивный ключ `frontend-test-key` и загрузите `tests/e2e/fixtures/review.mov`. Панель показывает число POST/GET. Для `slow` можно завершить существующее задание отдельной ссылкой панели. Выбор сценария сбрасывает тестовые задания, поэтому не переключайте его во время проверки восстановления. Стенд не подключается при production-сборке.

Подготовлена автоматизация Playwright: 21 сценарий для Chromium и WebKit, включая размеры 375/768/1366. Сборщик тестов обнаруживает все 42 проверки. Полный запуск этих 42 проверок здесь не выполнялся: браузерная проверка проведена через доступный Chrome. Для обычного CI:

```bash
pnpm exec playwright install --with-deps chromium webkit
pnpm test:e2e
```

Playwright использует перехват ответов API; реальная модель и сервер не нужны. При заданном `FRONTEND_TEST_URL` используется указанный dev-сервер без запуска второго процесса.

## Что ещё зависит от интеграции

Подтверждён конкретный MOV/H.264 в Chrome. Поддержку других кодеков в контейнере MOV, WebKit/Safari, реальное сенсорное управление и поведение overscroll на устройствах нужно проверить в целевых браузерах. При неподдерживаемом кодеке интерфейс показывает ошибку воспроизведения и оставляет доступными переданные сервером кадры. Качество модели, длительность обработки, CORS и работоспособность будущего внешнего API этой проверкой не подтверждаются.

## Доступность, локализация и объём сборки — 18.10.2026

- Скрытый системный input загрузки имеет `hidden`, `aria-hidden` и `tabindex=-1`; выбор файла открывает видимая native-кнопка с поддержкой Enter/Space. Skip-link переводит фокус на `main`. При обходе модального окна исключаются невидимые элементы и поля отключённого fieldset. Canvas не является лишней остановкой Tab.
- У текущего раздела есть `aria-current=page`, у одиночного выбранного события — `aria-current`, у плотной группы — `aria-expanded`. Плеер получил имя «Видеозапись». Существующие группы переключения вида и темы сохраняют свои выбранные состояния.
- Общие ключи «Открыть проверку» и «Открыть сервис» доступны вне словарей отдельных страниц. Проверка исходников разрешает все буквальные ключи `t(...)` в реально импортированном словаре. Во всех словарях проверяются KK/EN и совпадение параметров подстановки. Строки будущего API сохраняются как получены.
- Root error boundary не зависит от LocaleProvider: язык берётся из cookie, при недоступной cookie — из языка документа. Заголовок, инструкции, кнопки, подробности и запасной текст есть на RU/KK/EN; заголовок получает фокус. SSR-проверки выполняются для всех трёх языков.
- Three.js вынесен в динамический модуль. До приближения схемы к области просмотра и свободного времени браузера показывается SVG. При reduced motion, экономии трафика, ошибке загрузки или отсутствии WebGL остаётся доступная схема без смещения макета. Отложенные задания отменяются при уходе со страницы.
- Удалён полный импорт HeroUI CSS с повторным Tailwind. Подключаются только Table/Button/Checkbox/Chip; их стили остаются у страницы проверок. Глобальный Tailwind сканирует `app` и `components`, без сборок и документации.
