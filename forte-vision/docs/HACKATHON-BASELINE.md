# Forte Vision: исходное состояние для доработок

Дата проверки: 17 октября 2026 года. Источники: переданный архив проекта и семистраничное ТЗ «Datathon 26 — AI-сервис для выявления нарушений кассовой дисциплины по видеозаписям».

## Архитектура текущей версии

React 19 / TypeScript, маршруты App Router, Vinext / Vite, Tailwind CSS 4, HeroUI и Radix. Серверный маршрут принимает служебные ошибки; анализ видео не реализован. Авторизация удалена по запросу команды. На Sites приложение собирается для Cloudflare Workers. В `deploy/brev/` сохранён отдельный вариант Docker-развёртывания на Brev.

- `/` — лендинг; `/app` — рабочее пространство без входа, с помеченными примерами. Старые `/demo` и страницы входа перенаправляют на `/app`.
- `components/forte-workspace.tsx` — загрузка MOV до 250 МБ, предпросмотр, события, таймкоды, кадры и нормативные источники из ответа сервера, история в памяти вкладки, экспорт JSON.
- `lib/analysis.ts` — реальная отправка multipart-поля `file`, `X-API-Key`, опрос задания раз в 1,5 секунды, общий тайм-аут 5 минут, отмена ожидания, проверка структуры ответа.
- Регистрация, Supabase Auth, идентификация ChatGPT в приложении, auth API и middleware сессии удалены. Язык и тема доступны через меню настроек.
- Русский, казахский и английский интерфейсы; светлая, тёмная и системная темы; фирменные шрифты и SVG находятся в проекте.

Видео и результаты не сохраняются в серверную базу. Демо-записи — условные примеры, не результаты анализа пользовательского файла. Моделей, весов и датасета в архиве нет.

## Соответствие ТЗ

| Требование | Текущее состояние |
| --- | --- |
| Веб-интерфейс и загрузка MOV | Реализованы интерфейс и клиент отправки; обработчик отсутствует |
| Статус обработки и два вердикта | Поддерживаются в клиенте и экране результата; нужен настоящий сервер |
| Несколько событий, тип, таймкод, описание | Поддерживаются из ответа API |
| 1–3 JPEG-кадра в base64 на событие | Интерфейс умеет их показать; извлечение и формирование кадров отсутствуют |
| Связь события с правилом и актом РК | Поле источника отображается; проверенная нормативная база и сопоставление не реализованы |
| `POST /api/v1/analyze`, `GET /api/v1/jobs/{job_id}` | Есть клиент контракта; серверных маршрутов и проверки ключа жюри нет |
| Обработка за 5 минут | Есть клиентский тайм-аут; производительность анализа пока нельзя измерить |
| Локальные модели, обработка без интернета после загрузки весов | Моделей нет; это обязательное условие будущего сервера анализа |
| Проверка на новых видео и другом ракурсе | Пока не проводилась: данных и модели в поставке нет |
| Публичный UI и API для жюри | Веб-приложение открывается без входа; публичный доступ по ссылке включается в Sites при публикации. API жюри ещё не готов |

Авторизация, история и экспорт не обязательны по FAQ. Приоритет по оценке: обнаружение — 25 баллов; локализация — 15; классификация — 15; обоснованность правил — 15; устойчивость — 10; продукт — 10; техническое решение — 10.

## Следующий необходимый этап

1. Получить обучающие видео и разметку, определить видимые категории событий и проверенные источники РК. Не выводить финансовые или юридические факты, которых не видно в записи; идентификация лиц запрещена ТЗ.
2. Реализовать локальный сервер анализа с реальной моделью, извлечением кадров и обоими endpoint контракта. Отклонять неверный `X-API-Key`, хранить состояния `processing`, `done`, `failed` и укладываться в 5 минут.
3. Подключить интерфейс к серверу, проверить обычное видео, несколько событий, отсутствие нарушений, сбой задания и неизвестный ракурс. Для жюри предоставить доступный без браузерного входа API и ключ.

Cloudflare Workers используется здесь для текущего веб-приложения. Локальный ML-обработчик потребует отдельной среды команды; облачные AI API для обработки видео использовать нельзя.

## Развёртывание рабочей копии

Site, указанный в исходном архиве, вернул `NOT_FOUND` в текущем аккаунте. Переданные исходники импортированы в отдельный Site; оригинальный архив не изменён.

- Адрес: https://forte-vision-workbench.racingsnail10.chatgpt.site
- Рабочее пространство: `/app`; `/demo` перенаправляет туда.
- Требуемый доступ после обновления: публично по ссылке, без регистрации.
- При первоначальном импорте прошли 58 тестов. После удаления авторизации её тесты удалены вместе с кодом; добавлены проверки границ интервалов и пересечения маркеров.
- Автоматизация браузера в текущем окружении недоступна; интерактивный проход интерфейса не проверен.

Реальный анализ видео и интерактивная работа интерфейса не подтверждаются успешными unit-тестами или сборкой.

Интервалы просмотра включают до 3 секунд до и после таймкода. Первый экран результата показывает видео с интервалами. Нажатие на маркер открывает отдельный экран выбранного события: описание, кадры и источник. Описание не повторяется рядом с видео или ниже него. Возврат сохраняет позицию; «Смотреть фрагмент» включает воспроизведение выбранного интервала. Во время воспроизведения отмечается текущий интервал. Это контекст просмотра, а не гарантия точности детекции ±3 секунды.
