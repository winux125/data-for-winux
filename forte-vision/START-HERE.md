# Передача проекта Forte Vision

Каталог содержит исходный фронтенд, стили, локальные ассеты и тесты. Он подключён к API и локальным моделям родительского проекта и развёрнут по адресу https://154.54.100.194.sslip.io/app. В настройках API оставьте адрес пустым и введите выданный ключ. Актуальные ограничения RAG и инструкция развёртывания описаны в родительских README.md и docs/AUDIT.md.

## Запуск

Нужен Node.js 22.13+; версия pnpm зафиксирована в package.json.

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://localhost:5173/app. Авторизация пользователя не требуется. Чтобы получить реальные результаты проверки, подключите сервер команды в разделе «Подключение API».

## Проверки и сборка

Типы маршрутов создаются при запуске dev/build. На свежей распаковке их можно подготовить отдельно:

```bash
pnpm exec vinext typegen
pnpm typecheck
pnpm test
pnpm build
```

Для браузерных тестов:

```bash
pnpm exec playwright install chromium webkit
pnpm test:e2e
```
