# Forte Vision

Веб-интерфейс проверки видеозаписей кассовых операций для Datathon 2026. React / TypeScript, Vinext / Vite, Tailwind CSS 4, HeroUI и Radix. Фирменные SVG и шрифты хранятся в `public/brand/`.

## Текущая рабочая версия

https://154.54.100.194.sslip.io/app

`/app` открывает рабочее пространство без регистрации, пароля и пользовательской сессии. Все кнопки «Открыть сервис» ведут туда. Старые `/demo`, `/auth`, `/register` и страницы восстановления перенаправляют на `/app`. Формы аккаунтов, Supabase Auth, маршруты входа и проверки личности удалены. Публичный HTTPS-доступ обеспечивает Caddy на VM Brev.

Этот каталог содержит фронтенд. Он развёрнут вместе с API и локальными моделями из родительского проекта на NVIDIA Brev. Для подключения оставьте адрес API пустым и введите выданный ключ. Инструкция и актуальные ограничения находятся в родительских README.md и docs/AUDIT.md. Демо-записи и схема кассовой зоны помечены как примеры.

## Что работает

- Выбор MOV, drag and drop, проверка формата и размера до 128 МиБ, локальный предпросмотр при поддержке кодека браузером.
- Клиент загрузки с реальным прогрессом передачи, отдельными экранами обработки/ошибки/результата и отменой ожидания. История создаётся с начала загрузки; активная проверка доступна из любого раздела.
- Повтор безопасных запросов статуса при временном сбое, сохранение `job_id` и возобновление ожидания без повторного POST.
- Два итоговых вердикта; события с описаниями, таймкодами, кадрами, источниками и экспортом JSON.
- Интервалы для просмотра: до 3 секунд до и после корректного таймкода события, с обрезкой по началу и концу записи. Неизвестная длительность и таймкоды вне записи явно отмечаются; просмотр такого фрагмента недоступен. Это контекст просмотра, а не заявленная точность модели.
- Результат сначала открывает экран «Видеозапись»: итог, видео и интервалы на таймлайне. Полные описания событий здесь не дублируются.
- Значок «!» открывает отдельный экран события с одним описанием, кадрами и нормативным основанием. Доступны предыдущее/следующее событие и возврат к видео с сохранением позиции.
- Плеер имеет состояния загрузки, готовности и ошибки. При неподдерживаемом кодеке доступен переход к кадрам и описанию; действия воспроизведения не предлагаются.
- Кадры ограничены по количеству, объёму и разрешению. Повреждённые изображения получают заглушку без потери описания события.
- Кнопка «Смотреть фрагмент» открывает видео в выбранном интервале и останавливает воспроизведение в его конце. «Вся запись» снимает ограничение интервала.
- Таймлайн занимает до трёх строк. Плотные маркеры объединяются в группы; полный список событий доступен с пагинацией.
- История текущей вкладки: таблица и папки, поиск, фильтр, сортировка, удаление с Undo на 10 секунд и копирование ID. До окончания Undo сохраняются результат и локальное видео. На мобильных экранах доступны карточки.
- Разделы, проверки и события связаны с историей браузера. «Назад/вперёд» восстанавливают экран, позицию видео и режим фрагмента без повторной загрузки.
- Сохранённые параметры API отделены от соединения: связь подтверждается только реальным ответом API, ошибки доступа/транспорта отображаются отдельно, старое подтверждение помечается через минуту.
- Русский, казахский и английский языки; светлая, тёмная и системная темы в меню настроек.

Видео, API-ключ и результаты находятся только в памяти вкладки и сбрасываются при перезагрузке. Для незавершённых заданий только метаданные (номер задания, адрес сервера, имя, размер и длительность файла) сохраняются в sessionStorage до закрытия вкладки. После перезагрузки ожидание возобновляется вручную с тем же API; исходный MOV можно добавить локально для просмотра без новой отправки. Другие посетители не получают доступ к этим файлам или результатам через интерфейс.

## Локальный запуск

Node.js 22.13+ и pnpm из `package.json`:

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

В обычном локальном окружении адрес — `http://localhost:5173`. В управляемой среде используйте поддерживаемый механизм предварительного просмотра.

```bash
pnpm typecheck
pnpm test
pnpm build
```

`pnpm start` обслуживает локальный результат сборки через Wrangler и не публикует сайт. Для Brev сохранена инструкция `docs/BREV.md`.

## API анализа

В разделе «Подключение API» укажите HTTPS-origin сервера команды и `X-API-Key`. Ключ хранится в памяти текущей вкладки. Сохранение параметров не отправляет запрос и не подтверждает доступность сервера. При размещении API на том же origin адрес можно оставить пустым.

```text
POST /api/v1/analyze           multipart-поле file
GET  /api/v1/jobs/{job_id}     processing / done / failed
```

Для внешнего сервера требуется CORS на origin интерфейса. Лимит ожидания клиента — пять минут с начала загрузки. Отмена останавливает ожидание, но не гарантирует остановку задания на сервере. Контракт и формат результата: `docs/API.md`.

Отсутствие пользовательской авторизации не отменяет требование ТЗ о ключе жюри. Локальные модели и API развёрнуты в родительском проекте; ограничения положительных результатов RAG описаны в его docs/AUDIT.md.

## Основные файлы

- `components/forte-workspace.tsx` — состояние вкладки, загрузка, история и экран результата.
- `components/check-result.tsx` — отдельные экраны видеозаписи и разбора события.
- `components/event-timeline.tsx` — интервалы и переход к разбору.
- `lib/review-navigation.ts` — переходы между экранами, сохранение позиции и режим фрагмента.
- `lib/event-window.ts` — границы фрагментов и размещение маркеров.
- `lib/analysis.ts` — клиент сервера анализа и валидация ответов.
- `app/globals.css`, `app/themes.css` — раскладка и темы.
- `components/forte-landing.tsx` — лендинг.
- `docs/HACKATHON-BASELINE.md` — сопоставление текущей реализации с ТЗ.

Результаты проверки и инструкции для тестовых ответов API: `docs/FRONTEND-READINESS.md`. Сборка и тесты фронтенда не подтверждают качество ML-анализа или совместимость будущего внешнего API.
